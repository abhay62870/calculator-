# 🧮 Calculator Web App



A simple, responsive calculator built using **HTML, CSS, and JavaScript** that performs basic 

---

## ✨ Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🧹 Clear / Reset  
- 📱 Responsive design  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript

calculator/

## 🎮 How to Use

- Click numbers and operators  
- Press `=` to get result  
- Use `C` / `AC` to clear
